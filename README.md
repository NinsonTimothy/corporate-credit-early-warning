## Objective
Build an end-to-end machine learning project for predicting credit risk using public or synthetic data.

2. Data collection
3. Data quality assessment
4. Exploratory data analysis
5. Data preprocessing
6. Feature engineering
7. Baseline modelling
8. Model comparison
9. Evaluation and threshold analysis
10. Explainability
11. Deployment
12. Documentation
